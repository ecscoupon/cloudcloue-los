## CloudCone洛杉矶VPS性能测评小结

> 测试环境：Intel Xeon E5-2697 v2（1核 @2.70GHz），1GB内存，49G磁盘，KVM虚拟化，Debian12，BBR+fq拥塞控制，Multacom机房广播IP。

### 硬件与磁盘

CPU为E5-2697 v2单核，支持VT-x与AES-NI，不支持AVX2指令集，单核性能中等，仅适合轻量业务。内存1GB，开启气球回收与KSM内存复用。磁盘IO性能一般，混合读写50/50场景下大文件顺序读写最高约100MB/s，4K随机IO偏弱，不适合数据库等高IO负载场景。整机硬件加权总分14509，资源规格适合低负载应用。

### 网络、路由与IP质量

机房位于洛杉矶Multacom，广播IP，多库识别为机房商业IP，IP风险评价不一，部分平台标记高风险。流媒体全解锁，TikTok、Netflix、ChatGPT均可访问，邮件端口可用，IP无黑名单污染。
国内回程路由：电信NTT直连国内163骨干网；联通经由Verizon接入AS4837；移动走NTT对接CMI回国。国内访问延迟普遍160~270ms，移动线路丢包相对更高。回程带宽尚可，但**国内去程带宽严重受限**，国内单线程上传速度偏低，是主要短板。国际互联带宽尚可，跨洲访问稳定性一般。

### 适用场景

✅ 推荐场景：海外静态站点、流媒体解锁、轻量API、海外测试环境，对国内上行带宽无要求的业务。
❌ 不推荐场景：需要国内高速上传、低延迟交互、数据库等高IO业务，面向国内访客的网站。

> 测试脚本：HardwareQuality、IPQuality、NextTrace、单线程测速、fio磁盘测试
